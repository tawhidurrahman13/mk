Which
 
mitigation
 
would
 
best
 
prevent
 
this
 
attack?
 
 
A)  Deploying  endpoint  detection  and  response  (EDR)  solutions  
B)  Enforcing  multi-factor  authentication  (MFA)  
C)  Installing  a  host-based  intrusion  detection  system  (HIDS)  
D)  Implementing  network  segmentation  
 
Correct  Answer:  B)  Enforcing  multi-factor  authentication  (MFA)

A)  Continuous  monitoring

C)  Input  sanitization

benefits
 
most?
 
 
A)  Identifying  malware  signatures  in  files

4.  During  a  penetration  test,  a  tester  exploits  arbitrary  code  execution.  What  
should
 
happen
 
next?
 
 
A)  Escalate  privileges  
B)  Document  the  vulnerability  and  report  it  immediately  
C)  Continue  testing  
D)  Install  monitoring  software  
 
Correct  Answer:  B)  Document  the  vulnerability  and  report  it  immediately

5.  What  is  the  most  effective  way  to  ensure  cloud  data  security?  
 
A)  Encrypt  data  both  in  transit  and  at  rest  
B)  Use  a  dedicated  public  IP  
C)  Require  VPN  for  all  users  
D)  Perform  regular  pentests  
 
Correct  Answer:  A)  Encrypt  data  both  in  transit  and  at  rest

6.  Which  indicates  a  successful  DNS  poisoning  attack?  
 
A)  Users  redirected  to  malicious  websites  
B)  Increase  in  ARP  traffic  
C)  DNS  queries  failing  
D)  Unauthorized  DNS  logs  
 
Correct  Answer:  A)  Users  redirected  to  malicious  websites

7.  What  is  the  best  countermeasure  against  malicious  JavaScript  injection?  
 
A)  Enforce  strict  input  validation  
B)  Encrypt  user  data  
C)  Restrict  API  access  
D)  Require  MFA  
 
Correct  Answer:  A)  Enforce  strict  input  validation

8.  A  ransomware  message  appears  on  a  user’s  computer.  What  should  be  done  
first?
 
 
A)  Isolate  the  affected  device  from  the  network

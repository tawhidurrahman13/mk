If the error says client secret invalid

  1. Open Google Auth Platform, then open the same Web client shown below.
  2. Copy the Client secret from that exact client page.
  3. In Vercel, replace GOOGLE_CLIENT_SECRET with only the secret value.
  4. Redeploy the newest Vercel deployment with build cache off.

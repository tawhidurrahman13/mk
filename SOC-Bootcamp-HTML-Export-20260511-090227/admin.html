MacBook Codex Update Instructions
  1. Update macOS from System Settings before installing developer tools.
  2. Install or update Xcode Command Line Tools with xcode-select --install.
  3. Install the newest Codex desktop build, then sign back into GitHub from Codex connectors.
  4. Open the project folder, run npm start, and verify http://localhost:3000/login.html.
  5. If browser previews fail, restart Codex and confirm localhost permissions are allowed.
Production Environment Variables
  • GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET for real Google OAuth.
  • GOOGLE_OAUTH_REDIRECT_URI for the approved callback URL.
  • EMAIL_SMTP_HOST, EMAIL_SMTP_PORT, EMAIL_SMTP_USER, and EMAIL_SMTP_PASS for sending reset/MFA codes.
  • MFA_CODE_TTL_MINUTES and PASSWORD_RESET_TTL_MINUTES for code expiration policy.
  • AUTH_SESSION_SECRET for signing secure sessions on a backend.
